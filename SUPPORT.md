# Getting support

For a project-specific question, first check that repository's README and
documentation. If the problem persists, open a focused issue in the relevant
repository with a minimal reproduction, expected behavior and environment.
Use Discussions when a repository has enabled them.

For security vulnerabilities, **do not file a public issue**. Follow the
project's SECURITY.md and use GitHub's private vulnerability reporting where
available. Never include credentials, secret values or personal data in issues.

These independent open source projects are maintained as time permits;
commercial support and response-time guarantees are not offered. Contributions
and documentation improvements are welcome according to each repository's
CONTRIBUTING.md.
